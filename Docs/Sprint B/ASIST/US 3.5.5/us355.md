# US 3.5.5 — Remote Shell Login Control & Monitoring
**Role:** System Administrator  
**Objective:** Control and monitor access to remote Linux shells to prevent unauthorized access.

---

## Implemented Functionality

Only the following acceptance criteria were successfully implemented in the system.

---

## 1. Allowed Login Window (08:00–22:00)

Authentication through SSH is permitted **only** between **08:00 and 22:00** local time.

Attempts outside this time period are denied automatically.

### Implementation
Configured through `pam_time.so` with a rule in `/etc/security/time.conf`:

```
sshd;*;*;!Wk0800-2200
```

**Effect:**  
- Access allowed between 08:00 and 22:00  
- Access denied outside the allowed window  

---

## 2. MFA Requirement After Failed Login

After **any failed password authentication attempt**, the next login attempt must include **Google Authenticator MFA**.

### Implementation
Configuration in `/etc/pam.d/sshd` ensures:

- Failed login → next authentication attempts require `pam_google_authenticator.so`  
- Successful login → normal authentication flow resumes

**Effect:**  
- MFA (Google Authenticator) required only after a failure  
- No MFA required if login succeeds on first attempt  

---

##  Not Implemented
The following parts of the original story were **not** functional in the final implementation:

- ✖ Email alerting for failed login attempts  
- ✖ Automatic faillock monitoring and triggers  
- ✖ DNS stability for mail delivery  

These were excluded intentionally as requested.
